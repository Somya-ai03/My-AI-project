# AI Project Portfolio

This folder contains my personal AI projects built to explore natural language processing, chatbots, AI assistants, and interactive tools.

## Projects

### 1. Story Forge AI
- AI-powered story generation and revision workflow:
  1. **Write** – GPT generates an initial story.
  2. **Review** – Claude reviews and suggests improvements.
  3. **Revise** – GPT revises the story based on feedback.
- Interactive question-answering and website summarization features.
- [Open Story Forge AI notebook](./story_forge_ai.ipynb)

### 2. Airline AI Assistant
- AI chatbot for airline booking and queries.
- Interactive Gradio interfaces for user interaction.
- Logs conversations and answers user questions.
- [Open Airline AI Assistant notebook](./airline_ai_assistant.ipynb)

### 3. Questions Answer Assistant
- Standalone AI Q&A tool for general queries.
- Supports structured input and answers with context.
- [Open notebook](./questions_answer_assistant.ipynb)

### 4. Website Summarizer
- Summarizes websites into concise text using AI.
- Useful for quick content extraction and review.
- [Open notebook](./summarize_website.ipynb)

### 5. Gradio Chatbots / Interfaces
- `gradio_chatbot.ipynb` & `gradio_interface.ipynb` – Interactive AI interfaces built with Gradio.
- Demonstrates conversational AI and UI integration.

### 6. Data & Scripts
- `scraper.py` – Custom script for scraping data used in projects.
- `prices.db` – Sample dataset used in Airline AI Assistant project.

## Tech Stack

Python | NLP | Pandas | Gradio | Web Scraping | Automation

## How to Explore

- Open individual notebooks in Jupyter to try out each project.
- Run Gradio notebooks to see interactive AI assistant interfaces.
